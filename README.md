# Flash Tree
Inheritance graph builder for documentation generated by [Flash](https://github.com/geode-sdk/flash)

Note: For very large inheritance graphs, you may need to edit `path/to/venv/lib/python3.12/site-packages/mermaidx/engines/_common.py` (and maybe same of the following but change lib to lib64?) by replacing the existing `options` assignment with `options = {"config": config, "limit": 1_048_768} if config else {"limit": 1_048_768}` within `pele_render_script(...)`

## Usage
Positional (required) arguments
- `root_input` The path to the class you want to build the tree from.
- `root_folder` The directory that the flash-generated documentation is contained in.
- `root_output` Where to emit the mermaid output

Optional flag:
- `--backwards` Also retroactively look at what the given class inherited from. Can be useful if you want as much of everything as possible.

Example: `python do_tree.py ~/Documents/geode-docs-2/classes/cocos2d/CCObject ~/Documents/geode-docs-2 test.svg`

## Dependencies
See `requirements.txt`
- Install quickly with `pip install -r requirements.txt`.
    - I highly recommend setting up a virtual environment first (For example you can do `python -m venv desired/path/to/venv`) and activating it (For example `source desired/path/to/venv/bin/activate`)
